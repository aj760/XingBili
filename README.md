# XingBili

一个第三方哔哩哔哩电视TV App，支持触摸、遥控，适用于平板、TV、车机等设备。

## 功能概览

- 侧边栏导航：搜索 / 推荐 / 分类 / 动态 / 直播 / 我的/刷视频
- 扫码登录入口
- 视频播放：Media3(ExoPlayer)，支持分辨率/编码/倍速/字幕/弹幕等设置
- 设置页：播放与弹幕偏好等
